# Arslan Malik, portfolio website

Static site: plain HTML, CSS and JavaScript. No build step.

```
index.html
css/style.css
js/main.js
assets/img/   arslan.jpg, favicon.svg, detection.svg, tracking.svg
assets/docs/  Arslan_CV.pdf
```

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
1. Create a public repo named `meetarslanmalik.github.io`.
2. Upload all files, keeping the folder structure.
3. In the repo go to Settings, then Pages, choose the `main` branch and the root folder.
4. The site goes live at https://meetarslanmalik.github.io

## Edit
- Text and links: `index.html`
- Colors and type: the variables at the top of `css/style.css`
- Photo and CV: replace the files in `assets/` and keep the same names
